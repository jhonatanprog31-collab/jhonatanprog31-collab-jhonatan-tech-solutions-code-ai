🛠️ COMANDOS ÚTEIS
═════════════════════════════════════════════════════════════════════════════════

Ver status dos containers:
  $ docker-compose ps

Ver logs em tempo real:
  $ docker-compose logs -f

Ver logs específicos:
  $ docker-compose logs -f api         # Backend
  $ docker-compose logs -f web         # Frontend
  $ docker-compose logs -f db          # PostgreSQL
  $ docker-compose logs -f redis       # Redis

Parar containers:
  $ docker-compose down

Reiniciar:
  $ docker-compose restart

Recriar do zero:
  $ docker-compose down -v
  $ docker-compose up

⚠️ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

"Não consigo acessar localhost:3000"
  → Aguarde mais 5 minutos
  → Verifique: docker-compose ps
  → Veja logs: docker-compose logs -f web

"Erro de conexão ao API"
  → Aguarde mais 5 minutos
  → Reinicie: docker-compose restart api
  → Veja logs: docker-compose logs -f api

"Porta já em uso"
  → docker-compose down
  → docker-compose up

"Banco de dados não conecta"
  → Aguarde 30 segundos
  → Reinicie: docker-compose restart db
  → Veja logs: docker-compose logs -f db

"Limpar tudo e recomeçar"
  → docker-compose down -v
  → docker-compose up
