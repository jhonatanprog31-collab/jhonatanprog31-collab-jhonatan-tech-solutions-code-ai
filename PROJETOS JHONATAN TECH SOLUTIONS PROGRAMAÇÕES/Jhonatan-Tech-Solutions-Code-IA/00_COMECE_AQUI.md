# 🚀 COMECE AQUI - JHONATAN TECH SOLUTIONS CODE AI

## ⚡ 3 Passos para Começar (20 minutos)

### 1️⃣ Execute o Setup

**Windows (PowerShell):**
```bash
python JHONATAN_TECH_SOLUTIONS_CODE_AI_SETUP.py setup
```

**Mac/Linux:**
```bash
python3 JHONATAN_TECH_SOLUTIONS_CODE_AI_SETUP.py setup
```

### 2️⃣ Inicie o Projeto

```bash
docker-compose up
```

### 3️⃣ Acesse

- 🌐 Frontend: http://localhost:3000
- 📚 API Docs: http://localhost:8000/docs

## 📋 Requisitos

- Python 3.10+
- Node.js 18+
- Docker Desktop
- 8GB RAM mínimo
- 20GB de espaço em disco

## 📂 Estrutura Criada

```
.
├── backend/              ← API FastAPI
├── apps/web/             ← Frontend Next.js
├── scripts/              ← Scripts automação
├── docs/                 ← Documentação
└── docker-compose.yml    ← Docker config
```

## 🆘 Problemas?

- **Python não encontrado**: Instale em https://python.org
- **Docker não encontrado**: Instale em https://docker.com
- **Porta em uso**: `docker-compose down` e tente novamente
