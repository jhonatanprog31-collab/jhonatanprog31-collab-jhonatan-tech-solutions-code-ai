🔧 COMANDOS IMPORTANTES
═════════════════════════════════════════════════════════════════════════════════

Ver status:
  docker-compose ps

Ver logs:
  docker-compose logs -f        (Todos)
  docker-compose logs -f api    (Backend)
  docker-compose logs -f web    (Frontend)
  docker-compose logs -f db     (PostgreSQL)
  docker-compose logs -f redis  (Redis)

Parar:
  docker-compose down

Reiniciar:
  docker-compose up    (Reinicia tudo)
  docker-compose restart api    (Reinicia só backend)

Limpar e recomeçar:
  docker-compose down -v
  docker-compose up


⚠️ COMMON ISSUES & FIXES
═════════════════════════════════════════════════════════════════════════════════

"Port already in use"
  → docker-compose down
  → Aguarde 10 segundos
  → docker-compose up

"Banco não conecta"
  → Aguarde 30 segundos (primeira vez é mais lenta)
  → docker-compose logs -f db
  → docker-compose restart db

"Frontend branco/erro"
  → Recarregue página: Ctrl+F5
  → Limpe cache: Ctrl+Shift+Delete
  → docker-compose logs -f web

"Lento/Travando"
  → Verifique RAM: Precisa 8GB+
  → docker-compose logs -f
  → Reinicie: docker-compose restart
